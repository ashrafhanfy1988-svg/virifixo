Technical Review Guide
دليل المراجعة الفنية

English-first documentation for reviewers evaluating the VIRIFIXO demonstration workflow.

وثيقة تعريفية باللغة الإنجليزية أولاً، مع توضيحات عربية، لمساعدة المراجعين على فهم آلية عمل النسخة التجريبية.

1. Application Purpose | الغرض من التطبيق

VIRIFIXO is an independent media verification and review platform. It helps users inspect publicly available YouTube channel or video information and examine image and video files locally in their browser.

VIRIFIXO منصة مستقلة لمراجعة المحتوى الإعلامي، وتساعد المستخدم على فحص بيانات قنوات وفيديوهات YouTube العامة وتحليل ملفات الصور والفيديو محلياً داخل المتصفح.

2. YouTube Data API Workflow | آلية استخدام YouTube Data API

  1. The user enters one public YouTube channel URL or one video URL.
  2. The browser sends the submitted URL to the VIRIFIXO backend endpoint /api/verify.
  3. The backend requests the relevant public data through YouTube Data API v3 using the server-side configuration.
  4. The interface displays the fields returned by the service when available.

يدخل المستخدم رابط قناة أو فيديو عام، ثم ترسل الصفحة الرابط إلى خادم VIRIFIXO الذي يتعامل مع YouTube Data API v3، وتعرض الواجهة البيانات التي يعيدها الخادم عند توافرها.

The API key is not requested from the user and must not be placed in the public page. | لا يُطلب مفتاح API من المستخدم ولا ينبغي وضعه في صفحة الويب العامة.

3. Local File Review | مراجعة الملفات محلياً

  • Image and video files are selected from the user's device and previewed in the browser.
  • For images, the demo attempts to read available EXIF metadata, such as camera make/model, capture date, and GPS fields when present.
  • For videos, the demo can extract five sample frames for visual inspection.

يتم اختيار الملفات ومعاينتها في المتصفح. ويحاول النظام قراءة بيانات EXIF المتاحة للصور، كما يستخرج خمس لقطات نموذجية من الفيديو للمراجعة البصرية.

4. Results and Limitations | النتائج والقيود

  • Returned metadata depends on the availability and permissions of the source data.
  • EXIF metadata may be absent, incomplete, or altered before a file reaches the user.
  • Extracted video frames are samples and do not represent every moment in the video.
  • The demonstration does not claim to make a definitive automated judgment about authenticity, manipulation, or credibility.

تعتمد النتائج على البيانات المتاحة. وقد تكون البيانات الوصفية غائبة أو غير مكتملة، كما أن الإطارات المستخرجة عينات فقط. ولا تدّعي المنصة إصدار حكم آلي نهائي بشأن أصالة المحتوى أو التلاعب به أو مصداقيته.

5. Privacy and Terms | الخصوصية والشروط

Please review the Privacy Policy and Terms of Use for the published information about data handling and permitted use.

يرجى مراجعة سياسة الخصوصية وشروط الاستخدام المنشورتين لمعرفة تفاصيل التعامل مع البيانات وضوابط الاستخدام.

6. Independence and Non-Affiliation | الاستقلال وعدم الارتباط

VIRIFIXO is an independent project. It is not affiliated with, endorsed by, or officially partnered with YouTube or Google.

VIRIFIXO مشروع مستقل، ولا تربطه شراكة رسمية أو اعتماد أو تبعية لشركتي YouTube أو Google.
