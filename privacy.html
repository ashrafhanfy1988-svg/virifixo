العودة إلى VIRIFIXO

سياسة الخصوصية – VIRIFIXO

آخر تحديث: 17 نوفمبر 2026

خدمات YouTube API

تستخدم ميزة فحص قنوات وفيديوهات YouTube خدمات YouTube Data API v3 لجلب بيانات عامة مثل العنوان والوصف ومعرف القناة والإحصاءات العامة وتاريخ النشر والصورة المصغرة. لا تطلب المنصة تسجيل الدخول إلى Google أو كلمات المرور أو رموز التفويض، ولا تعدّل بيانات YouTube.

يخضع الاستخدام إلى شروط خدمة YouTube وسياسات مطوري YouTube API.

البيانات التي تتم معالجتها

  • رابط القناة أو الفيديو الذي يرسله المستخدم للفحص.
  • البيانات العامة التي تعيدها YouTube Data API.
  • ملفات الصور والفيديو التي يختارها المستخدم؛ تتم معاينتها وتحليلها محلياً داخل المتصفح ولا ترفعها واجهة VIRIFIXO إلى خادمها.
  • قد تعالج GitHub Pages وRender بيانات تقنية وسجلات تشغيل مثل عنوان IP ووقت الطلب وفق سياساتهما.

الاستخدام والتخزين والمشاركة

يمر رابط الفحص عبر خادم VIRIFIXO إلى YouTube Data API ثم تعاد النتيجة إلى المتصفح. لا تنشئ النسخة الحالية حسابات أو قاعدة بيانات لطلبات الفحص أو نتائجها، ولا تبيع البيانات أو تستخدمها للإعلانات. لا تنشئ المنصة ملفات تعريف ارتباط للتتبع. وقد يحتفظ مزودو الاستضافة بسجلات تقنية وفق سياساتهم.

الملفات وبيانات EXIF

يتم تحليل الملفات محلياً في المتصفح. قد تحتوي الصور على موقع الالتقاط أو وقت التصوير أو طراز الكاميرا؛ راجع هذه البيانات قبل مشاركة النتائج. تستخدم الصفحة مكتبة ExifReader عبر jsDelivr وقد يتلقى مزودها طلباً تقنياً عند تحميل المكتبة.

الاحتفاظ والحذف

لا توفر النسخة الحالية حسابات مستخدمين أو تخزيناً دائماً لنتائج الفحص أو ملفات الوسائط. لا توجد نتائج محفوظة في حساب لدى VIRIFIXO لحذفها. سجلات مزودي الاستضافة تخضع لسياساتهم. حذف بيانات الفحص لدى VIRIFIXO لا يحذف المحتوى أو البيانات لدى YouTube.

الأمان والتواصل

لا تشارك كلمات مرور Google أو بيانات حساسة. لمراجعة المشروع أو التواصل مع مالكه، استخدم مستودع VIRIFIXO على GitHub.
