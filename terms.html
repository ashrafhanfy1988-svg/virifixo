شروط استخدام VIRIFIXO

آخر تحديث: 17 نوفمبر 2026

طبيعة الخدمة

VIRIFIXO أداة مساعدة تجريبية لمراجعة بيانات المصادر العامة وتحليل ملفات الوسائط محلياً. النتائج مؤشرات مساعدة وليست حكماً نهائياً على صحة المحتوى أو أصالته أو هوية ناشره، ولا تضمن اكتشاف التزييف.

YouTube

تستخدم ميزة الفحص YouTube Data API v3. باستخدامها توافق على الالتزام بشروط خدمة YouTube وسياسات مطوري YouTube API إضافة إلى هذه الشروط.

الاستخدام المقبول

  • استخدم المنصة لأغراض قانونية فقط.
  • لا تعطل الخدمة أو تتجاوز حدودها أو تسيء استخدام API.
  • لا تستخدم النتائج للتشهير أو المضايقة أو اتخاذ قرارات عالية الأثر دون تحقق مستقل.
  • احترم حقوق النشر والخصوصية وشروط المنصات.

الملفات المحلية

تتم معالجة الصور والفيديو المختارة محلياً في المتصفح. يتحمل المستخدم مسؤولية امتلاك حق استخدام الملفات ومراجعة بيانات EXIF، بما فيها الموقع الجغرافي، قبل مشاركة النتائج.

التوفر وحدود المسؤولية

تقدم الخدمة حسب التوفر وقد تتعذر بعض البيانات بسبب إعدادات الخصوصية أو قيود YouTube أو الحصة أو الأعطال. يتحمل المستخدم مسؤولية التحقق من المصادر الأصلية وعدم الاعتماد حصراً على مخرجات المنصة.

الملكية والتواصل

تظل الحقوق في عناصر المنصة المملوكة لصاحب المشروع محفوظة. صفحة المشروع: مستودع VIRIFIXO على GitHub.
